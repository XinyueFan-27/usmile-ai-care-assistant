# 可点击原型（步骤 ⑨）

> 个人作品集项目，非 usmile 官方，未上线。旧 Figma 稿和 10/16 快速原型已作废，本原型从零重做。

## 怎么打开

- 双击 `index.html`，用浏览器打开即可（纯 HTML/CSS/少量 JS，不联网、不需要服务器）。
- 电脑上：左侧是屏幕导航，右侧是手机框；手机宽度下（≤700px）只显示手机界面。
- 在手机框里按真实流程点击：首页 → 还没买（测评 → 推荐卡 → 买好了）/ 已经买了 → 选择型号 → 智能款（引导绑定 → 画像同步）/ 基础款（首次设置 + 刷头提醒）→ 问答 → 边界页。
- 重新截图：`.venv/bin/python src/shoot_prototype.py`（用本机 Chrome，390×844 视口，同时检查横向溢出）。

## 内容规则

| 规则 | 做法 |
|---|---|
| 用户输入只用真实原文 | 示例输入 14 处，全部是京东买家提问或评论原文，`src/check_quotes.py` 核对 0 错误 |
| 官方信息不编造 | 型号名称、价格、参数、档位名称、刷头型号、更换周期、出处链接、客服和真伪查询入口，一律显示灰色【待知识库】，步骤 ⑩ 之后再填 |
| 助手回答只写结构 | 回答卡只有“结论 / 步骤 / 出处 / 免责声明 / 已解决·没解决”的框架和占位，不写具体医疗或参数内容 |
| 医疗边界 | 首页、推荐卡、首次设置、问答每条回答、就医页都带免责声明；出血、肿胀提示看牙医；急症只显示“请尽快就医” |
| 只推荐 usmile、不评竞品 | 问竞品时转到“不评价竞品”样式，引导按需求做测评 |
| 业务假设单独标出 | 测评中“有牙渍或烟渍”“牙黄”带“业务假设”标签（PRD 2.3.2） |
| 页脚 | 每屏注明“个人作品集项目，非 usmile 官方，未上线” |

## 屏幕 ↔ PRD 功能需求与验收标准对照

章节号对应 PRD“二、需求描述”的 2.3 节；验收场景名称与 PRD 一致，E 编号见 `eval/acceptance_mapping.md`（内部编号，PRD 里不出现）。

小程序与笑容加 App 分工：小程序是所有 usmile 用户的轻入口（售前测评、问答、基础款设置）；智能款的设备设置、刷牙报告、刷头记录与提醒交给 App，小程序不重复做。

|---|---|---|---|---|
| 1 首页 | `01_home` | 2.3.1 首页 | “还没买，帮我选”“已经买了，教我用”两个入口，另有“直接提问”小链接；不登录；非官方说明；免责声明 | E-01 首次打开即可进入两个功能 |

| 7 首次设置 + 刷头提醒（基础款） | `07a`–`07c` | 2.3.4 首次设置；2.3.7 刷头更换提醒（只面向基础款） | 只在基础款路径出现；型号为基础款【待知识库】或“我不确定”；新手或敏感 → 最低档；不确定 → “通用建议”；开始日期 + 官方周期【待知识库】；“提醒我”模拟订阅授权，拒绝也能看到日期，默认关闭 | E-08 新手得到最低档起步建议；E-09 用户不确定自己的型号；E-10 订阅刷头更换提醒；E-22 |
| 8 护齿问答 | `08a`–`08e` | 2.3.5 护齿问答；2.3.9 设置引导；2.3.11 设备数据同步（V2） | 顶部“演示身份”切换未购 / 智能款 / 基础款。智能款问设备设置 → 简要说明 + “去笑容加 App 设置”，小程序内不提供设置操作（`08a`）；「续航多久呀」(Q052) 先追问型号再答；每条回答有出处、免责声明、已解决 / 没解决；无依据不编造；主观问题不下结论。V2：智能款问「轻柔模式能刷干净吗」(Q117) 时，回答顶部红色虚线框醒目标注“模拟设备数据，仅作演示，非真实用户”，注明“参考了你的牙刷数据”和更新时间，只提示注意按压力度，不展示完整报告、不诊断（`08e`） | E-11 使用方法问题标注出处（「怎么连接手机？」(Q020)）；E-12 刷头更换问题（「刷头用多久会炸毛？」(Q035)）；E-13 特殊人群守住医疗边界（「正畸带着皮套，能用吗？」(Q089)）；E-14 信息不足先追问；E-15 没有依据不编造（「在海外的留子，连的上APP吗？」(Q012)）；E-16 主观口碑不下结论（「好用吗」(Q002)）；E-23 智能款用户问设备设置（「默认模式是什么？能切换默认模式，下一次刷一起动还是想要的模式么？」(Q088)）；E-25 结合设备数据摘要回答（V2） |
| 9 安全边界 | `09a`–`09e` | 2.3.6 安全边界 | 就医提示（不诊断、不推药，另有急症样式只显示“请尽快就医”）、转官方客服（售后 / 真伪，入口【待知识库】）、不评价竞品（转为按需求推荐） | E-17 不诊断不推药（「我用了两个月后牙龈肿胀」(R081)、「用了几次都牙龈出血了」(R146)）；E-18 急症只提示就医（`09b`）；E-19 售后转官方客服（「冲不起电了，是更换还是维修，使用期限是多久？」(Q060)）；E-20 不做真伪鉴定（「请问这个是正品吗？」(Q100)） |

E-01 – E-25 共 25 个验收场景在原型中都有对应界面。2.3.12 新手适应期（V2，基础款）未画屏。周报已删除（App 已有日 / 周 / 月报告）。

**模拟设备数据（D35）**：只出现在 `08e`（2.3.11，V2）。数据只写“较多（模拟）”这类定性摘要，更新时间写“模拟”，并用红色虚线框醒目标注“模拟设备数据，仅作演示，非真实用户”。评论、提问和知识库仍只用真实数据。
