**附加标记 `claim_gap`（是/否）（v1.0 新增，v1.1 补充，D18）**：用户表达“实际效果低于宣传，或低于自己买之前的预期”。包括明确提到宣传、广告、噱头，以及“没有想象的那么…”“期望太高”“以为…结果…”这类说法。只说贵、不值、配不上价格，算“性价比”，不算 claim_gap。例：「与宣传的充一次电用60天，完全不一样，过度宣传」(R063)；「没有想象的那么准确」(R065)。理由：这类落差多半是信息没对齐，和 `info_need` 一起看。 **注意（D20）：第二批抽检 claim_gap 只有 80%，标为 true 的精确率 50%，因此只做定性举例，不报比例。**

## 三、评论级标记

| 字段 | 取值 | 定义 | 例句 |
|---|---|---|---|
| `info_need` | 是 / 否 | 这条反映的问题，**如果用户事先知道正确信息就能避免或缓解**：不会用、不会选、不懂规则、期望和实际不符 | 是：「以为是那种超声波牙刷，用来才知道是一个能自己摆头的牙刷」(R009)；「不知道一次电可以用几次啊」(R107)；「问客服怎么使用，客服都不知道」(R066)<br>否：「没用两天就故障」(R158)（纯硬件故障，信息帮不上） |
| `ai_can_help` （v1.1 新增，D18） | 是 / 否 | 比 `info_need` 宽：针对这条评论反映的问题，一个**只提供信息的护齿问答助手**（产品说明、使用指导、选购建议、口腔科普；不能修产品、不能处理售后）能给出有实际帮助的提示，减轻问题或让下次避免。`info_need` 为是时，这一项一定为是。没有问题的正面评论、generic 评论为否 | 是：「不能关机」(R013)（可告知关机或防误触方法）；「牙刷有点硬」(R040)（可提示敏感牙龈选软毛刷头、轻柔模式）；「电池不咋抗用」(R099)（可说明真实续航和充电习惯）<br>否：「没用两天就故障」(R158)（要维修）；「买了不到一周就降价」(R110)（价保，助手处理不了） |
| `generic`（v1.0 新增） | 是 / 否 | 没有任何具体功能信息的评价，含模板式好评（可能是刷单） | 「非常满意的一次购物，物有所值，比实体店里实惠多了！」(R003) |
| `overall_sentiment` | 正 / 负 / 中 | 整条评论的情感 | — |

说明：第 ① 步的 `low_info` 只抓了 4 条 8 字以内的；`generic` 由 LLM 判断，能抓到“用着感觉不错，挺好的”(R079) 这种长一点的空话。`generic = 是` 的评论不进痛点矩阵。

`frequency_type`（反复出现 / 集中出现 / 个别）是主题层面的标记，第 ⑥ 步按统计结果算，不逐条打。

## 五、商品问答分类（118 条）

| # | 类别 | 定义 | 例句 |
|---|---|---|---|
| Q1 | 选购对比 | 型号之间、品牌之间怎么选 | 「y30和p20pro推荐哪个」(Q13)；「飞利浦跟这个怎么选」(Q40) |
| Q2 | 适用人群 | 敏感、正畸、补牙、儿童、牙龈萎缩等能不能用 | 「正畸带着皮套，能用吗？」(Q89)；「补的牙可以刷吗」(Q102) |
| Q3 | 使用方法 | 怎么操作、怎么连 App、模式怎么设 | 「怎么连接手机？」(Q20)；「默认模式是什么？能切换默认模式」(Q88) |
| Q4 | 刷头与配件 | 刷头兼容、数量、软硬、充电器配件 | 「t300的牙刷头可以用吗」(Q107)；「刷头用多久会炸毛？」(Q35) |
| Q5 | 售后与质量 | 能用多久、坏了怎么办、正品验证 | 「冲不起电了，是更换还是维修」(Q60)；「请问这个是正品吗？」(Q100) |
| Q6 | 产品参数（v1.0 新增） | 续航、充电方式、防水、噪音、频率等可以查说明书回答的问题 | 「充一次电用多久」(Q85)；「请问是type c充电的吗」(Q62) |
| Q7 | 效果与口碑（v1.0 新增） | 泛泛地问“好用吗”“值不值” | 「好用吗」(Q2)；「请问这牙刷不会像imask一样是智商税吧？」(Q92) |
| Q8 | 其他 | 以上都不是（颜色、补贴、库存等） | 「哪个颜色更好看？」(Q16) |

一条问题可以有多个类别，第一个写主类别。例：「牙齿敏感的人适合这一款吗」(Q81) → Q2。

**问答 `info_need`（v1.1 收紧，D16）**：true = 问题有确定答案，AI 助手能直接用官方说明、产品参数、口腔科普或使用指导回答；不依赖其他用户的主观体验，也不需要处理具体订单。

| 取值 | 类型 | 例句 |
|---|---|---|
| true | 参数、使用方法、配件兼容、适用人群、型号区别、按需求推荐型号 | 「Y30的振动频率是多少」(Q7)；「t300的牙刷头可以用吗」(Q107)；「y30和p20pro推荐哪个」(Q13) |
| false | 主观口碑 | 「好用吗」(Q2) |
| false | 需要个案处理（售后、正品验证、补贴） | 「请问这个是正品吗？」(Q100) |
| false | 个人偏好 | 「哪个颜色更好看？」(Q16) |

## 六、LLM 输出格式（第 ③ 步用）

每条评论输出一个 JSON：

```json
{
  "review_id": "R065",
  "tags": [{"tag": "F7", "sentiment": "负面", "evidence": "识别不准确左右牙老是弄混"}],
  "non_product_tags": [],
  "info_need": false,
  "claim_gap": false,
  "ai_can_help": false,
  "generic": false,
  "overall_sentiment": "负"
}
```

`evidence` 必须是原文片段，第 ④ 步抽检时程序先自动核对“是不是原文的子串”，再人工看对不对。

## 七、验收

人工抽检 50 条（按型号分层随机），判断每条的标签和情感是否正确，准确率 ≥ 85%；达不到就改定义后重跑。
