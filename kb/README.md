# 知识库（kb/）

> 个人作品集项目，非 usmile 官方。这里是 RAG 问答 Demo 的**唯一资料来源**：回答只能依据这里的内容，并标注出处。

## 目录

| 路径 | 内容 |
|---|---|
| `sources.md` | 来源清单（编号 S = 品牌官方，A = 权威科普） |
| `model_attributes.csv` | 型号属性表，给推荐规则用；每个字段带出处列 |
| `models/` | 在售型号与价格段、Y30 / P10 / U7 Pro 详细资料、其他型号官网参数 |
| `brush_heads/` | 刷头款式、适配、官方更换周期 |
| `usage/` | 官方使用建议（首次用什么模式、牙齿敏感、防水、换区提醒等） |
| `app/` | 笑容加 App 介绍、适配机型、地区限制 |
| `service/` | 客服热线、防伪查询、保修、官方购买渠道 |
| `oral_health/` | 权威口腔科普：刷牙方法、牙刷更换、牙龈出血、正畸、补牙、儿童 |

## 每一块的格式

每个知识块以 `### 编号 标题` 开头，下面固定 5 行，再接正文：

```
### KB-xxx-01 标题
- 适用：型号名，或“通用”
- 来源：Sxx / Axx（名称 + 链接见 sources.md）；图片内容注明“详情图第 n 张，OCR 识别、已人工核对”
- 来源级别：1 品牌官方 / 2 权威科普
- 抓取日期：2026-10-18
- 类型：参数 / 使用建议 / 科普 / 服务

要点：自己整理的一两句话（检索和回答主要用这段）。
原文摘录：「……」（只摘必要的短句，逐字照抄）
```

- 「」里的原文必须与来源逐字一致；要点是自己的话，不加引号。
- 找不到官方依据的写【待核实】，不用第三方补。
- 同一事实在多个来源一致时，列出全部来源；不一致时两种说法都写，并说明差别（例如 P10 续航）。

## 版权与存放

- 公开仓库（kb/）只放：必要的短摘录（逐字）+ 自己整理的要点 + 来源链接。
- 长篇原文和图片不提交，存放在 `data/processed/kb_raw/`（已被 `.gitignore` 排除）：
  - `img/<型号>/`：京东详情页图片；`ocr_<型号>.txt`：OCR 结果；`jd_<型号>_spec.txt`：规格参数表
  - `official/`：usmile 官网各页正文
  - `authority/`：权威科普原文（PDF 及提取的文字）
  - `jd_price_snapshot_2026-10-18.txt`：京东价格快照
- 重新抓取：`.venv/bin/python src/kb_fetch_official.py`、`cd src && ../.venv/bin/python kb_fetch_authority.py`、`.venv/bin/python src/kb_ocr.py <型号> <图片链接清单>`。

## 已知局限

- 没有找到公开的电子版说明书；“使用方法”只来自商品详情页的官方说明和研发师解答，说明书条目【待核实】。
- 价格是 2026-10-18 京东官方自营店的标价快照，促销期间会变，只用来划分价格段。
- 官网下载页标注 App V4.0.0，适配列表可能未随新品更新（见 `app/app.md`）。
- 详情页里的功效数字（如菌斑清除率）多为“内部实验室”数据，知识库只在原文里保留脚注口径，不作为推荐理由。
